# Icons

App icons from the [Solar icon set](https://www.figma.com/community/file/1166831539721848736)
by [480 Design](https://www.figma.com/@480design), licensed
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

The `linear` variants are vendored as vector PDFs converted from the
[Iconify](https://iconify.design/) distribution. Regenerate with `scripts/fetch-icons.sh`.

`redact.pdf` is drawn in `design/svg/redact.svg`. Its frame is Solar's `stop-linear`, so that the
rectangle and redaction tools share one shape, with a mosaic added inside. Same licence.
Regenerate with `scripts/make-icon.sh`.

# Backdrops

Gotham, Arendelle, Sierra Mist and Island Waves backdrop stops are exact
[Hypercolor](https://hypercolor.dev/) values by [Jordi Hales](https://github.com/jordihales/hypercolor),
licensed [MIT](https://github.com/jordihales/hypercolor/blob/main/LICENSE).
The remaining presets are k-means palettes sampled from backdrop.love previews as inspiration
and recreated as plain CSS, never the photos.
